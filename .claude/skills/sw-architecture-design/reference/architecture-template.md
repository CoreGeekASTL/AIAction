# 系统架构设计文档模板

> 本文件为 sw-architecture-design skill 的输出文档模板。SKILL.md 中通过引用链接加载本文件。

## 文档模板

```markdown
# {特性名称} — {服务名} 系统架构设计

## 一、需求背景
### 1.1 文档信息（版本/作者/日期）
### 1.2 目标
### 1.3 范围（包含/不包含）
### 1.4 存量代码分析（可复用模块表 + 技术栈确认 + 代码约定）
> **承载设计要素**：C1 目录结构, C4 命名规则

## 二、整体设计
### 2.1 架构总览（mermaid flowchart）
> **承载设计要素**：R1 运行形态, C2 分层规则, M1 对象角色
### 2.2 数据流图（mermaid）
> **承载设计要素**：D1 数据来源, D2 数据流图, M4 通信图, L5 业务流程
### 2.3 组件职责表（组件 | 职责 | 技术栈）
> **承载设计要素**：L2 实体职责（细化）, M1 对象角色
### 2.4 关键设计决策表（决策 | 选择 | 原因）
> **承载设计要素**：C5 扩展思路, M3 交互方式, R2 实例策略, R4 消息处理能力

## 三、接口设计
> **承载设计要素**：L4 逻辑接口, M2 消息定义, R3 接口约束, R7 安全约束
### 3.x 每个接口（API | 方法 | 协议 | 请求参数 | 响应格式 | 示例）

## 四、DB 表结构设计
> **承载设计要素**：D3 数据结构(DB), D6 并发访问分析
### 4.x 每张表（DDL + 字段说明 + 并发分析 + 锁机制）

## 五、配置项
（配置键 | 默认值 | 说明 | 来源）
```

## 设计要素承载总览

| skill | 承载的设计要素 | 充分性判断 |
| --- | --- | --- |
| 系统架构设计 | C1 目录结构 + C2 分层规则 + D2 数据流图 + D3 数据结构(DB) + R1 运行形态 + R3 接口约束 | 六项核心要素齐全，缺一不可 |

> 设计要素来源于 SPEC 设计要素矩阵，每个标注 `> **承载设计要素**` 的章节必须填写实质内容。
